1- En Windows abrir una terminal cmd y ejecutar:
ssh-keygen -t ed25519 -C "mi-pc"

-Presiona Enter para guardarla en la ruta por defecto C:/Users/TU_USUARIO/.ssh/id_ed25519 (normalmente esta carpeta esta oculta, tienes que habilitar ver 'Elementos ocultos' en tu carpeta de tu TU_USUARIO
-Si quieres, puedes ponerle una contraseña (passphrase) para que, si alguien te roba la laptop, no pueda usar tu key.
-Si le pusiste un passphrase, cada vez que hagas conexión por ssh con tu key, te pedirá ese passphrase para continuar.
-Por defecto el nombre de las keys será algo como: id_ed25519

SI DESEAS PUEDES CAMBIARLE EL NOMBRE A LAS KEYS


***
2- Pasar la key pública (el candado) a tu Ubuntu
-Ahora necesitas copiar el contenido de tu key pública (tu_key.pub) dentro de tu Ubuntu.
-En Windows, ve a tu carpeta donde se generó tus keys, abre el archivo tu_key.pub con el Bloc de Notas y copia todo su contenido (es una sola línea de texto largo).
-Abre una terminal cmd y conectate por SSH a tu maquina ubuntu:
(Ejemplo)
ssh ubuntu@192.168.18.94

-Una vez dentro de Ubuntu, crea la carpeta por si acaso y abre el archivo de llaves con el editor de texto con el siguiente comando:
mkdir -p ~/.ssh && nano ~/.ssh/authorized_keys

-Te abrirá un editor de texto apuntando al archivo authorized_keys y ahí debes pegar el contenido de tu archivo tu_key.pub
-Guarda los cambios presionando Ctrl + O, luego Enter para confirmar, y sal con Ctrl + X


**
3- Ahora conéctate localmente (o simula conectandote desde afuera usando datos de celular, tu servidor ubuntu deberá tener asignado una ip publica):
ssh -i /tu_ruta/tu_key usuario@IP_DE_TU_UBUNTU

Ejemplo:
ssh -i /C:/Users/BILLY/.ssh/sv_l4d2 ubuntu@192.168.18.23

-Verás que entra directamente y sin pedirte la contraseña de tu usuario (solo te pedirá la contraseña de la key si decidiste ponerle el passphrase).
-Tu key privada habrá abierto de forma segura el candado en tu Ubuntu.


************ELIMINAR INGRESO SSH POR CONTRASEÑA PARA MAS SEGURIDAD (OPCIONAL)
⚠️ Advertencia importante: ¡No hagas esto hasta que estés 100% seguro de que puedes entrar con tu key SSH! Si desactivas las contraseñas y tu key no funciona bien, podrías perder el acceso remoto a tu servidor.

1- Una vez configurado correctamente la conexión por ssh mediante key, el ingreso ssh por contraseña sigue activo el cual puedes usarlo con el siguiente comando desde tu pc Windows:
ssh -o PubkeyAuthentication=no usuario@IP_DE_TU_UBUNTU

Ejemplo:
ssh -o PubkeyAuthentication=no ubuntu@192.168.18.23

La instrucción 'PubkeyAuthentication=no' le indica a ssh que no solicite la key para realizar la conexión, ssh te pedirá la contraseña del usuario para conectarse.

2- En caso quieras que la conexión SSH sea sólo con la key, conectate a tu ubuntu con tu key y ejecuta lo siguiente:
sudo nano /etc/ssh/sshd_config.d/50-cloud-init.conf

-Busca la línea que dice 'PasswordAuthentication yes' y cámbiala a 'PasswordAuthentication no'
-Guarda el archivo (Ctrl + O, luego Enter) y sal (Ctrl + X).
-Reinicia el servicio de SSH para aplicar los cambios:
sudo systemctl restart ssh

-Si en caso te aparece que el archivo '50-cloud-init.conf' no existe, prueba ejecutando:
sudo nano /etc/ssh/sshd_config
-Busca la línea que dice '#PasswordAuthentication yes' y cámbiala a 'PasswordAuthentication no' (borra el caracter '#')
-Guarda el archivo y reinicia el servicio SSH.
-Una vez reiniciado el servicio SHH, cuando quieras conectarte no te dejará usar la contraseña manual.


************REACTIVAR CONEXION SSH CON CONTRASEÑA Y ELIMINAR CONEXION CON KEYS
1- Inicia sesión en tu Ubuntu como lo haces normalmente usando tu key privada desde tu pc. Mantén esta ventana de la terminal abierta durante todo el proceso como tu salvavidas.

2- Abre el archivo de configuración:
sudo nano /etc/ssh/sshd_config.d/50-cloud-init.conf
o
sudo nano /etc/ssh/sshd_config

-Busca la línea 'PasswordAuthentication no' y cámbiala de nuevo a 'PasswordAuthentication yes'
-Guarda los cambios (Ctrl + O, Enter) y sal (Ctrl + X).
-Reinicia el servicio SSH:
sudo systemctl restart ssh

3- Prueba el acceso por contraseña (¡SIN CERRAR LA VENTANA ACTUAL!)
-Abre una nueva ventana de la terminal en tu pc e intenta conectarte obligando al sistema a pedirte la contraseña:
ssh usuario@IP_DE_TU_UBUNTU

Ejemplo:
ssh ubuntu@192.168.18.94

Si te pide tu contraseña de Ubuntu y logras entrar con éxito, significa que el camino de las contraseñas ya está activo y seguro.

4- Borra la llave autorizada
-Ahora que ya confirmaste que puedes entrar con tu contraseña, ya puedes borrar de forma segura el archivo de keys en tu Ubuntu para que nadie más entre con key:
sudo rm ~/.ssh/authorized_keys

-Si intentas ingresar por ssh con el comando 'ssh -i /tu_ruta/tu_key usuario@IP_DE_TU_UBUNTU' verás que te pedirá la password, confirmando así que está ignorando tu key por que se borró del archivo 'authorized_keys'.


***********************************************************INFORMACION
***Qué hace: ssh-keygen -t ed25519 -C "mi-pc"
-Este comando sirve para crear tu par de keys SSH (el candado y la llave) utilizando el método más moderno y seguro que existe actualmente.

**Desglose del comando
ssh-keygen 
Es la herramienta interna de tu sistema encargada de generar (crear), administrar y convertir llaves de seguridad para SSH.

-t ed25519 
El parámetro -t significa Type (Tipo). Aquí le estás diciendo qué algoritmo matemático usar para encriptar la key. Al elegir ed25519, estás usando el estándar de oro actual: es increíblemente seguro, las firmas son muy rápidas de procesar y los archivos resultantes son muy pequeños.

-C "mi-pc" 
El parámetro -C sirve para agregar un Comment (Comentario). Este texto se escribe al final de tu key pública (la que va en el servidor). No afecta la seguridad, pero es tu etiqueta de identificación. Así, cuando entres a tu servidor (o a GitHub) y veas la lista de keys autorizadas, sabrás de inmediato que esa llave en específico pertenece a tu laptop personal y no a otra máquina.

¿Qué pasa cuando lo ejecutas?
-Al darle Enter a ese comando, la terminal te hará un par de preguntas para finalmente guardar dos archivos en tu carpeta oculta C:\Users\Usuario\.ssh\ en Windows
id_ed25519 (La Llave Privada): Tu llave física que nunca debe salir de tu computadora.
id_ed25519.pub (La Llave Pública): El candado que contiene la etiqueta "mi-pc" al final y que subirás a tu Ubuntu de casa, a Azure o a GitHub.
