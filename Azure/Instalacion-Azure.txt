**************************CONEXION A LA VM(máquina virtual) E INSTALACION DE ARCHIVOS NECESARIOS ******************************
Una vez creada y prendida nuestra VM(Ubuntu 22) con IP pública en la nube, desde Windows procedemos:

1- NOS CONECTAMOS MEDIANTE SSHH A LA MAQUINA VIRTUAL:
-Abre una terminal cmd en Windows y ubicate en la carpeta donde hayas guardado 'tu_key.pem' de la nube, y ejecutamos:
ssh -i tu_key.pem azureuser@IP_PUBLICA_VM

-TODA LA LINEA DE TU CMD DEBE FIGURAR ASI:
C:\Users\TU_USUARIO\carpeta_donde_esta_la_key>ssh -i tu_key.pem azureuser@IP_PUBLICA_VM

(EJEMPLO):
C:\Users\BILLY\az-vm-l4d2>ssh -i vm-azure.pem azureuser@57.156.56.2

-EN CASO TU VM TENGA OTRO NOMBRE DE USUARIO, DEBERAS CAMBIARLO POR ESE:
ssh -i tu_key.pem tu_usuario@57.156.56.2

-Dar aceptar y entraremos a nuestra VM.


***
2- INSTALACION DE ARCHIVOS NECESARIOS EN LA VM (Ejecutamos uno por uno), dar 'si o yes' en caso nos pida confirmación:
sudo dpkg --add-architecture i386 # enable multi-arch  
sudo apt-get update && sudo apt-get upgrade
sudo apt-get install libc6:i386 # install base 32bit libraries
sudo apt-get install lib32z1
sudo apt-get install screen


***
3- AGREGAMOS UN USUARIO A LA VM CON NOMBRE 'STEAM':
-El siguiente comando nos pedirá crear un password (no olvidar el password):
sudo adduser steam

-Nos pedirá llenar FullName, Home Phone, etc. Simplemente dejar vacio, presionar enter y luego confirmar con 'y'.

-El siguiente comando brinda permisos sudo al usuario creado.
sudo adduser steam sudo

El siguiente comando nos pedirá nuestro user y password para loguearnos con ese usuario creado:
sudo login


*****************************INSTALACION DE STEAM Y SERVIDOR DEDICADO L4D2 EN LA VM ***************************** 
4- ASEGURATE DE ESTAR LOGUEADO CON EL USUARIO 'STEAM' EN LA VM

INSTALAMOS STEAM EJECUTANDO LOS SIGUIENTES COMANDOS (uno por uno):
wget http://media.steampowered.com/installer/steamcmd_linux.tar.gz
tar -xvzf steamcmd_linux.tar.gz

INSTALAMOS EL SERVIDOR DEDICADO L4D2 (ejecuta ambas lineas):
./steamcmd.sh +force_install_dir ./Steam/steamapps/common/l4d2 +login anonymous +@sSteamCmdForcePlatformType windows +app_update 222860 validate +quit && \./steamcmd.sh +force_install_dir ./Steam/steamapps/common/l4d2 +login anonymous +@sSteamCmdForcePlatformType linux +app_update 222860 validate +quit

SI AL EJECUTAR LA PRIMERA VEZ NOS MUESTRA "@sSteamCmdForcePlatformType"= "windows", significa que hay que volver a ejecutar el comando anterior.

5- EN TU MAQUINA WINDOWS DESCARGA O CLONA LO SIGUIENTE (ARCHIVOS ZONEMOD):

-Ubicamos en nuestra pc el archivo 'srcds1' en la ruta \L4D2-Competitive-Rework\Dedicated Server Install Guide\srcds1
-Abrimos el archivo srcds1 con algun editor de texto (block de notas o notepad++).
-Ponemos la Private IPv4 address de la VM dentro del archivo srcds1 en el apartado 'IP' y guardamos cambios.


***
6- ASIGNAR ADMINS EN EL SERVIDOR L4D2
-Para asignar admins se debe modificar el archivo 'admins_simple.ini' de la ruta \L4D2-Competitive-Rework\addons\sourcemod\configs\
-Ingresamos a la página https://steamid.io
-Ingresamos el link de nuestro perfil steam en esa página y nos mostrará un campo como -> STEAM_1:1:104132302
-Abrimos el archivo admins_simple.ini con un editor de texto y agregamos al final de ese archivo lo siguiente:
"STEAM_1:1:104132302"  "99:z" 
-Donde "STEAM_1:1:104132302" debes cambiarlo por tu steamID, "99:z" significa que ese steamID tendrá permisos admin en el servidor.
-Guardamos cambios.


***
7- AHORA MOVEMOS EL ARCHIVO SRCDS1 DESDE NUESTRA PC A LA VM:
-Abrimos una nueva terminal cmd en nuestra PC en la carpeta donde está la key de la vm.
-Ejecutamos el siguiente comando (usar toda la ruta donde este el archivo srcds1):

(Ejemplo):
scp -i vm-azure.pem "E:\Instaladores de Programas\l4d2-zonemod\git\L4D2-Competitive-Rework\Dedicated Server Install Guide\srcds1" azureuser@57.156.56.2:/home/azureuser/

-Una vez copiado el archivo, sólo se muestra el nombre del archivo en la terminal (confirmando así el éxito del copiado).
-Volvemos al SSH conectado a la VM, debemos estar con la sesión del usuario principal 'azureuser', si en caso tu SSH esta con el usuario 'steam' logueado, ejecuta lo siguiente para salir de la sesión y volver al usuario principal:
exit

-Una vez ubicado en el usuario principal, ejecutamos el siguiente comando para mover el archivo srcds1 en la VM:
sudo cp -r /home/azureuser/srcds1 /etc/init.d/


***
8- DAMOS PERMISOS PARA QUE SE PUEDA EJECUTAR EL ARCHIVO SRCDS1:
sudo chmod +x /etc/init.d/srcds1

11- DEBEMOS ABRIR LOS PUERTOS TCP/UPD 27015 EN LA CONFIGURACION DE RED DE LA VM:

12- ARRANCAMOS EL SERVIDOR CON EL SIGUIENTE COMANDO:
sudo /etc/init.d/srcds1 restart

-Al ejecutar el comando debe mostrar lo siguiente:
Stopping L4D2 Dedicated Server #1 on port 27015: L4D2_Server1 ... done.
Starting L4D2 Dedicated Server #1 on port 27015: L4D2_Server1 ... done.

-Para ver la consola del servidor L4D2 en vivo, estando dentro del usuario steam para verificar que el servidor está corriendo correctamente (debe mostrar varios comandos del juego ejecutandose):
screen -r L4D2_Server1 

-Para salir de screen sin cerrar el proceso del servidor dedicado:
ctrl a d 

-Si vemos los comandos ejecutandose significa que nuestro servidor L4D2 ya está iniciado, para conectarnos al servidor debemos abrir la consola en el juego y ejecutar:
connect IP_PUBLICA_VM:27105


***
13- CREAR UNA SALA PARA JUGAR EN EL SERVIDOR:
-Abrimos el juego.
-Creamos una sala de espera en modo enfrentamiento.
-Escogemos 'Mejor Dedicado Disponible'.
-Abrimos la consola del juego e ingresamos el comando mm_dedicated_force_servers + la ip 
(Ejemplo):
mm_dedicated_force_servers 57.156.56.2:27105

-Damos enter, esto hará que la sala de espera esté asociada al servidor.
-En la sala damos iniciar partida cuando haya suficientes jugadores (OJO QUE EL SERVIDOR TIENE QUE ESTAR VACIO PARA PODER UNIRNOS DESDE LA SALA DE ESPERA, SI EN CASO HAY JUGADORES EN EL SERVIDOR TENDRAS QUE BOTARLOS PARA PODER CREAR UNA PARTIDA DESDE LA SALA, PARA BOTARLOS PUEDES USAR EL COMANDO DE REINICIO DE SERVIDOR EJECUTANDO 'sudo /etc/init.d/srcds1 restart' EN TU VM, UNA VEZ REINICIADO EL SERVIDOR DEBES ESPERAR UNOS 15SEG ANTES DE ARRANCAR LA SALA PARA QUE LE SERVIDOR CARGUE TODA LA CONFIGURACION NECESARIA).

***IMPORTANTE
-Si el servidor detecta que todos los jugadores se han desconectado, este se reiniciará aprox en 30seg.
-En caso se haya terminado una campaña y quieres volver a crear otra sala, debemos esperar aprox 30seg para que
el servidor se reinicie, si en caso no deseas esperar ese tiempo debes ejecutar otra vez el comando 'sudo /etc/init.d/srcds1 restart' en el cmd
conectado a la vm, una vez reiniciado debes esperar unos 15 seg antes de arrancar la sala para que el servidor cargue toda configuracion necesaria. 


***
14- CREAR UN SERVICIO EN UBUNTU PARA QUE ARRANQUE EL SERVIDOR L4D2 AL PRENDER LA VM:
-En la VM ejecuta:
sudo nano /etc/systemd/system/l4d2.service

-Se abrirá un editor de texto, pega todas las siguientes líneas tal cual:

[Unit]
Description=Left 4 Dead 2 Server
After=network.target

[Service]
Type=oneshot
ExecStart=/etc/init.d/srcds1 start
ExecStop=/etc/init.d/srcds1 stop
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target

-Guarda el archivo con:
1- CTRL + O
2- Enter
3- CTRL + X

-Recarga systemd:
sudo systemctl daemon-reload

-Activar para arranque automático:
sudo systemctl enable l4d2

-Arrancar el servicio:
sudo systemctl start l4d2

-Verifica estado:
sudo systemctl status l4d2

(Opcional)
-Limpiar errores si ocurrió una falla al iniciar el servicio :
sudo systemctl reset-failed

16- COMANDOS ADMIN
- Para usar nuestros comandos admin en el servidor L4D2 debemos ingresar en el chat del juego '!admin o /admin' y se abrirá una ventana con distintos comandos que podemos ejecutar en el juego.

ATAJOS (debes ejecutar los siguientes comando en el chat del juego):
-Kickea a un jugador de la partida (el nombre del jugador debes escribirlo exacto como tambien sólo escribir una parte de su nombre):
!kick nombreJugador

-Banear a un jugador del servidor:
!ban <#userid|nombreJugador> <minutos|0> [razón]

Banea un jugador por tiempo limitado o permanente (si pones 10, 60, etc serán los minutos de baneo, si pones 0 el baneo será permanente), indicar la razón es opcional. 

Ejemplo:
!ban NoobMaster69 0 uso de multihacks

-En caso el jugador a banear tiene un nombre vacío o con carácteres raros, deberás abrir la consola del juego y escribir 'status', al ejecutarlo te mostrará los jugadores conectados en la partida (algo similar a lo siguiente):
#  21 1 "jugador1" STEAM_1:1:104132302 13:29 23 0 active
#  22 2 "jugador2" STEAM_1:1:104132302 13:29 23 0 active
#  14 3 "jugador3" STEAM_1:1:104132302 13:29 23 0 active
#  55 4 "jugador4" STEAM_1:1:104132302 13:29 23 0 active
#  12 5 "☆☆☆☆" STEAM_1:1:104132302 13:29 23 0 active

-Para banearlo debes usar su #userid el cual es el primer número de la izquierda(debes incluir el símbolo #), ejemplo:
!ban #12 0 uso de multihacks

-Para desbanear a un jugador debes ejecutar:
!unban STEAM_ID_DEL_JUGADOR

Ejemplo:
!unban STEAM_1:1:104132302

-Los usuarios baneados se guardan en el archivo ubicado en /cfg/banned_user.cfg
